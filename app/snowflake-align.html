Keys: left/right move a, up/down move b (hold Shift for 10 steps). Index correspondence compares the block with the whole at the same parameter, endpoint-gauged; free fit allows a least-squares complex dilation instead, and is reported for comparison only. Copy mode fits w(t) ≈ c·W(s0 + s1·t) + d — a similarity image of the whole with a freely chosen affine parameter — by a coarse grid followed by two local refinements. Drag the green copy on the overlay to move it; set the drag control to rotates and scales it (or hold Shift) to transform it about its centre instead. The sliders set the scale, the rotation and the parameter range; refit all six re-runs the search. When the interval moves, the copy follows it by default — the correspondence between block and arc is affine, so the arc moves by the same multiple of the block's displacement and the similarity is untouched; choose the copy stays put to freeze it instead. Note that with the block taken from the same curve the index correspondence matches exactly, so copy mode only says something when the two curves differ. r/R compares endpoint chord ratios; its percentile is taken among the chords of the same index gap. With distance to the other curve the residual is instead the distance from each curve to the piecewise-linear interpolant of the other, in both directions (601 sample points, so it is sampled rather than exact). The right-hand panel is the distortion heatmap of the whole curve on $I\times I$: blue at the minimum, red at the maximum, white at the geometric mean, with the minimum and maximum marked and crosses at the current chord.
