Keys: left/right move a, up/down move b (hold Shift for 10 steps). Index correspondence compares the block with the whole at the same parameter, endpoint-gauged; free fit allows a least-squares complex dilation instead, and is reported for comparison only. Copy mode fits w(t) ≈ c·W(s0 + s1·t) + d — a similarity image of the whole with a freely chosen affine parameter — by a coarse grid followed by two local refinements. The sliders set the scale, the rotation and the parameter range, re-fitting the translation; refit all six re-runs the search. Note that with the block taken from the same curve the index correspondence matches exactly, so copy mode only says something when the two curves differ. r/R compares endpoint chord ratios; its percentile is taken among the chords of the same index gap. With distance to the other curve the residual is instead the distance from each curve to the piecewise-linear interpolant of the other, in both directions (601 sample points, so it is sampled rather than exact).
